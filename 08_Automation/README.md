# Test Automation

## Planned starting point

After the manual test cases and defect retesting are complete, the automation phase may begin with:
1. Set up a Playwright project using JavaScript or TypeScript.
2. Automate a small set of stable smoke tests, such as successful login and product listing visibility.
3. Add sorting and cart workflow tests.
4. Store test scripts in `Playwright_Test_Scripts/`.
5. Store genuine Playwright reports and screenshots in `Automation_Reports/`.
